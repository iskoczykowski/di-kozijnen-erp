# D&I Kozijnen Premium ERP

Next.js + Supabase Projekt für Kunden, Projekte, Produktion, Lager, Montage, Kalender, Mitarbeiter, QR, Kamera, Angebote, Rechnungen und Mehrsprachigkeit.

## Start lokal
npm install
npm run dev

## Vercel
Repository importieren und deployen. Später Supabase ENV Variablen eintragen:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_ANON_KEY
